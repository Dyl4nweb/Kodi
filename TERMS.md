## 1. Description of Service
KODI is a free, open-source, local-first Windows desktop utility that provides a floating Dynamic Island and notch interface for Windows 10 and 11. It features Google Antigravity quota indicators, media controls via Windows Global System Media Transport Controls (GSMTC), hardware status monitors, and productivity quick actions.
